One number, digits only: the honest count of open browser tabs on this machine at build time. The program writes it to `/output/entry.txt`.

Entry: "0"

Counted firsthand at build time: no browser process is running on this machine and no live browser session state exists, so the browser is closed and zero tabs are open — the surprising end of the field, where everyone expects a hoarder's dozen.
